# DSAI Project Portfolio

A curated portfolio of selected Data Science, AI, and algorithmic projects. Each project is kept in its own top-level directory with a dedicated README, tests, and reproducibility notes.

## Projects

- **hkmu-ai-study-assistant** — persistent multi-PDF RAG application with OCR, citations, FAISS, SQLite, tests, Docker, and CI.
- **ev-purchase-prediction-ensemble** — leakage-safe Kaggle-style classification pipeline with 5-fold OOF validation, nested target encoding, LightGBM/CatBoost, and OOF-only blending.
- **kaggriculture-tournament-agent** — self-contained strategy agent for scheduling, logistics, resource allocation, market timing, and opponent-aware decisions.

A fourth research-reproduction project involving caregiver survey data is kept in a private repository because participant-level data governance requires additional review before public release.

## Verification

The portfolio revision compiles all included Python files and includes dependency-light tests for each project. Performance claims are limited to results supported by the original project artifacts; no unverified leaderboard score is presented as measured fact.
